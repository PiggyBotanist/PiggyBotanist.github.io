01. Vectors and Norms

A vector $\mathbf{v} \in \mathbb{R}^n$ is an ordered $n$-tuple of real numbers, often represented as a column. Vectors are the basic objects in linear algebra and appear as feature vectors, parameter vectors, gradients, and encodings in high-dimensional manifolds. Basic Definitions Zero vector: $\mathbf{0} = [0, \ldots, 0]^T$. Unit vector: A vector $\mathbf{u}$ with $|\mathbf{u}| = 1$. To normalize a nonzero $\mathbf{v}$: $$ \hat{\mathbf{v}} = \frac{\mathbf{v}}{\|\mathbf{v}\|} $$ Linear combination: $\mathbf{w} = c_1 \mathbf{v}_1 + \cdots + c_k \mathbf{v}_k$ for scalars $c_i \in \mathbb{R}$. Span: The set of all linear combinations $\text{span}({\mathbf{v}_i}) = { \sum c_i \mathbf{v}_i }$. 02. Geometry and Products

Geometry in $\mathbb{R}^n$ is induced by the inner product, which allows for the definition of angles, orthogonality, and projections. 1. Inner Product Spaces (IPS) An inner product $\langle \cdot, \cdot \rangle$ on a vector space $\mathcal{V}$ is a mapping $\mathcal{V} \times \mathcal{V} \to \mathbb{F}$ satisfying: Conjugate Symmetry: $\langle \mathbf{u}, \mathbf{v} \rangle = \overline{\langle \mathbf{v}, \mathbf{u} \rangle}$. Linearity: $\langle c\mathbf{u} + \mathbf{w}, \mathbf{v} \rangle = c\langle \mathbf{u}, \mathbf{v} \rangle + \langle \mathbf{w}, \mathbf{v} \rangle$. Positive Definiteness: $\langle \mathbf{v}, \mathbf{v} \rangle \ge 0$ and $\langle \mathbf{v}, \mathbf{v} \rangle = 0 \iff \mathbf{v} = \mathbf{0}$. 03. Matrices

A matrix $A \in \mathbb{F}^{m \times n}$ represents a linear transformation $T: \mathbb{F}^n \to \mathbb{F}^m$. In high-dimensional contexts, we view matrices as structured operators rather than mere data grids. 1. Fundamental Definitions For $A \in \mathbb{R}^{m \times n}$, the entry in the $i$-th row and $j$-th column is denoted $a_{ij}$ or $[A]_{ij}$. Transpose: $A^T$ where $[A]^T_{ij} = a_{ji}$. Trace: Only for square matrices ($n \times n$), $\text{Tr}(A) = \sum_{i=1}^n a_{ii}$. Cyclic Property: $\text{Tr}(ABC) = \text{Tr}(BCA) = \text{Tr}(CAB)$. 2. 06. Matrix Inverses

An invertible matrix (or non-singular matrix) represents an operator that can be “undone.” If $A$ maps $\mathbf{x}$ to $\mathbf{b}$, then $A^{-1}$ maps $\mathbf{b}$ back to $\mathbf{x}$. 1. Definition and Existence A square matrix $A \in \mathbb{F}^{n \times n}$ is invertible if there exists a matrix $A^{-1}$ such that: $$ AA^{-1} = A^{-1}A = I_n $$ Uniqueness: If an inverse exists, it is unique. Existence Condition: $A$ is invertible if and only if $\det(A) \neq 0$. Singular Matrix: A square matrix with no inverse ($\det(A) = 0$). 2.
