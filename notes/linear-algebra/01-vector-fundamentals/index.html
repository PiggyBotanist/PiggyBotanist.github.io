01. Vector Fundamentals

January 1, 2024 · 1 min · 177 words · Your Name
Table of Contents
  • Basic definitions
  • Vector norms
  • Norm properties

A vector $\mathbf{v} \in \mathbb{R}^n$ is an ordered $n$-tuple of real numbers, often represented as a column. Vectors are the basic objects in linear algebra and show up as feature vectors, parameter vectors, gradients, and encodings.

Basic definitions#

  • Zero vector: $\mathbf{0} = [0, \ldots, 0]^T$.
  • Unit vector: A vector $\mathbf{u}$ with $|\mathbf{u}| = 1$. To normalize a nonzero $\mathbf{v}$: $$ \hat{\mathbf{v}} = \frac{\mathbf{v}}{|\mathbf{v}|} $$
  • Linear combination: $\mathbf{w} = c_1 \mathbf{v}_1 + \cdots + c_k \mathbf{v}_k$ for scalars $c_i$.

Vector norms#

A norm $|\cdot|$ maps vectors to non‑negative reals. The $p$-norm ($p \ge 1$) is

$$ \|\mathbf{v}\|_p = \left( \sum_{i=1}^n |v_i|^p \right)^{1/p} $$

Special cases:

  • $L_1$ norm (Manhattan): $|\mathbf{v}|_1 = \sum_i |v_i|$.
  • $L_2$ norm (Euclidean): $|\mathbf{v}|_2 = \sqrt{\sum_i v_i^2} = \sqrt{\mathbf{v}^T \mathbf{v}}$.
  • $L_\infty$ norm (max): $|\mathbf{v}|_\infty = \max_i |v_i|$.

Norm properties#

Every norm satisfies:

  1. $|\mathbf{v}| \ge 0$ and $|\mathbf{v}| = 0 \iff \mathbf{v} = \mathbf{0}$.
  2. $|c\mathbf{v}| = |c|,|\mathbf{v}|$ (homogeneity).
  3. $|\mathbf{u} + \mathbf{v}| \le |\mathbf{u}| + |\mathbf{v}|$ (triangle inequality).

In ML and statistics, norms measure size and are used for regularization (e.g. $L_1$ / $L_2$ penalties) and distance metrics.
