07. Linear Combinations and Span

January 1, 2024 · 1 min · 179 words · Your Name
Table of Contents
  • Linear combinations
  • Span
  • Linear independence

Linear combinations and span describe all vectors you can generate from a set; linear independence tells you whether those generators are redundant.

Linear combinations#

A vector $\mathbf{v}$ is a linear combination of ${\mathbf{v}_1,\dots,\mathbf{v}_k}$ if

$$ \mathbf{v} = c_1 \mathbf{v}_1 + \cdots + c_k \mathbf{v}k = \sum{i=1}^k c_i \mathbf{v}_i $$

for some scalars $c_i$.

Span#

The span of $S = {\mathbf{v}_1,\dots,\mathbf{v}_k}$ is

$$ \text{span}(S) = \left{ \sum_{i=1}^k c_i \mathbf{v}_i : c_i \in \mathbb{R} \right}. $$

  • $\text{span}(S)$ is always a subspace.
  • To test if $\mathbf{b} \in \text{span}{\mathbf{v}_1,\dots,\mathbf{v}_k}$, solve $[\mathbf{v}_1\ \cdots\ \mathbf{v}_k \mid \mathbf{b}]$; if consistent, $\mathbf{b}$ is in the span.

Linear independence#

${\mathbf{v}_1,\dots,\mathbf{v}_k}$ is linearly independent if

$$ c_1 \mathbf{v}_1 + \cdots + c_k \mathbf{v}_k = \mathbf{0} $$

implies $c_1 = \cdots = c_k = 0$ (only the trivial combination gives zero). Otherwise, the set is linearly dependent.

Practical tests:

  • Form $A = [\mathbf{v}_1\ \cdots\ \mathbf{v}_n]$. Columns are L.I. iff $\text{rank}(A) = n$ (no free variables).
  • For $n$ vectors in $\mathbb{R}^n$, they are L.I. iff $\det(A) \neq 0$.

A minimal spanning set (spans but has no redundancy) is precisely a basis.
