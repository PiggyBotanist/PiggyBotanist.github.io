08. Basis and Dimension

January 1, 2024 · 1 min · 172 words · Your Name
Table of Contents
  • Basis
  • Basis theorem and dimension

A basis is a minimal generating set for a space; dimension is the number of vectors in any basis.

Basis#

$\mathcal{B} = {\mathbf{b}_1,\dots,\mathbf{b}_n}$ is a basis for a subspace $H$ if

  1. $\mathcal{B}$ is linearly independent.
  2. $H = \text{span}(\mathcal{B})$.

Then every $\mathbf{x} \in H$ has a unique coordinate representation

$$ \mathbf{x} = c_1 \mathbf{b}_1 + \cdots + c_n \mathbf{b}_n. $$

Basis theorem and dimension#

If $V$ is $p$‑dimensional:

  • Any L.I. set of exactly $p$ vectors in $V$ is a basis.
  • Any spanning set of exactly $p$ vectors in $V$ is a basis.
  • $\dim(V)$ is the number of vectors in any basis.

Consequences:

  • If $\dim(V)=n$, any set of more than $n$ vectors is dependent.
  • If $\dim(V)=n$, no set of fewer than $n$ vectors can span $V$.

Change of basis#

Let $\mathcal{B}$ and $\mathcal{C}$ be bases of the same space. The transition matrix

$$ P_{\mathcal{C} \leftarrow \mathcal{B}} = \big[ [\mathbf{b}1]{\mathcal{C}}\ \cdots\ [\mathbf{b}n]{\mathcal{C}} \big] $$

converts coordinates:

$$ [\mathbf{x}]{\mathcal{C}} = P{\mathcal{C} \leftarrow \mathcal{B}} [\mathbf{x}]_{\mathcal{B}}. $$

Its inverse $P_{\mathcal{B} \leftarrow \mathcal{C}} = (P_{\mathcal{C} \leftarrow \mathcal{B}})^{-1}$ maps back.\n
